# Moldova Drought Risk

A data pipeline that turns monthly station SPEI values into district-level drought severity for Moldova, exported as a spatial table for a CARTO Builder dashboard.

> **Synthetic data: not real observations.**
> The climate values in this project were generated to mimic the statistics of Moldovan station records. They are not measurements and must not be used to judge actual drought conditions in Moldova. The project demonstrates the pipeline, not the climate.

## What it does

1. Loads monthly SPEI-3 for 16 station locations (1961–2020).
2. Classifies each month into the WMO / McKee et al. (1993) severity bands.
3. Assigns stations to Moldova's first-level administrative districts.
4. Exports a spatial table (GeoParquet + CSV) ready to load into CARTO.

## Quick start (Windows, PowerShell)

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -e . --no-deps
pytest
```

`requirements.txt` pins the exact versions the project was tested with. `pip install -e .` then installs this package in editable mode, without re-resolving those versions.
